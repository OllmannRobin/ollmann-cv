# Front-End Web Developer CV

A modern, clean, and responsive digital CV built with **React**, **TypeScript**, and **Tailwind CSS v4**.

## 🚀 Tech Stack

* **Framework:** React
* **Build Tool:** Vite
* **Language:** TypeScript
* **Styling:** Tailwind CSS v4

## 📁 Project Architecture

```text
src/
├── assets/             # Profile picture and icons
├── components/         # Modular UI components (Header, Body, Skills, etc.)
├── types/              # TypeScript definitions
├── App.tsx             # Application root
└── main.tsx            # Entry point
